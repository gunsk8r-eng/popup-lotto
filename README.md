# popup-lotto

ป๊อปอัปผลหวยสำหรับติดบนเว็บ (ผลล่าสุด / ตรวจหวย / ย้อนหลัง / เลขเด็ด) — เลือกประเภทหวยได้จากแถบด้านบนของป๊อปอัป

| ประเภท | `type=` | แหล่งข้อมูล |
|---|---|---|
| 🇹🇭 สลากกินแบ่งรัฐบาล | `th` | API กองสลาก (glo.or.th) |
| 🇱🇦 หวยลาวพัฒนา | `lao` | check-lottery.com |
| 🇻🇳 หวยฮานอย (เฉพาะกิจ / พิเศษ / ปกติ / VIP) | `hanoi` | check-lottery.com |
| 📈 หวยหุ้น (ไทย นิเคอิ ฮั่งเส็ง จีน เกาหลี ไต้หวัน สิงคโปร์ อินเดีย อังกฤษ เยอรมัน ดาวโจนส์) | `stock` | Yahoo Finance (ดัชนีปิด) |
| 🏦 สลากออมสิน | `gsb` | imhuay.com |
| 🌾 สลาก ธ.ก.ส. | `baac` | imhuay.com |
| 🇲🇾 หวยมาเลย์ (Magnum 4D) | `malay` | check4d.org |

## ติดตั้ง

```html
<script src="https://cdn.jsdelivr.net/gh/gunsk8r-eng/popup-lotto@main/lotto.js?v=3" defer></script>
```

พารามิเตอร์เสริม: `&type=lao` (ประเภทที่เปิดเป็นค่าแรก), `&auto=0` (ปิดการเด้งเองวันหวยรัฐบาลออก), `&lc=…` (ไลฟ์แชท), `&fb=1` (ตารางบอล)

## อัปเดตผล

GitHub Actions (`.github/workflows/lotto.yml`) รัน `node update-lotto.js` ทุก 15 นาทีช่วง 15:00–22:59 น. และชั่วโมงละครั้งในช่วงอื่น แล้ว commit `lotto.json` เมื่อผลเปลี่ยน
ถ้าแหล่งข้อมูลประเภทไหนดึงไม่ได้ จะเก็บผลเดิมของประเภทนั้นไว้และขึ้นคำเตือนในหน้า Actions

**หวยหุ้น** คิดจากดัชนีปิด: 3 ตัวบน = เลขหน้าจุดทศนิยม 1 ตัว + หลังจุด 2 ตัว, 2 ตัวล่าง = เลขหลังจุด 2 ตัวของค่าเปลี่ยนแปลง (แต่ละเว็บอาจใช้กติกาต่างกัน)
